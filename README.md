# E-Commerce-Sales-Analytics-
An interactive E-Commerce Sales Analytics Dashboard built using Microsoft Power BI to analyze sales, profit, orders, quantity, cost, and profit margin across different categories, regions, and time periods.

# E-Commerce Sales Analytics Dashboard

## Project Overview
This project transforms raw e-commerce sales data into an interactive business intelligence dashboard for understanding overall sales performance and product-level performance.

## Key Features
- **KPI Analysis:** Total Sales, Total Profit, Total Orders, Total Quantity, Profit Margin, and Total Cost.
- **Category Analysis:** Category-wise sales and profit analysis.
- **Regional Analysis:** Region-wise sales performance.
- **Sales Trends:** Year-month sales trend analysis.
- **Interactive Filters:** Date and Category slicers.
- **Product Drill-through:** Product-level performance analysis.
- **Category Details:** Dedicated page with a product performance table.

## Tools & Technologies
- Microsoft Power BI
- DAX
- Power Query
- Data Modeling
- Excel / CSV

## Data Model
The report uses four separate tables connected through relationships for interactive analysis:

- **Customer:** Customer-related information.
- **Product:** Product and category details.
- **Sales:** Transaction-level sales data.
- **Date:** Calendar data for time-based analysis.

## Skills Demonstrated
Data Cleaning • Data Transformation • Data Modeling • DAX Measures • Data Visualization • KPI Reporting • Interactive Dashboards • Drill-through Analysis

## Project Objective
To convert raw e-commerce data into a clear and interactive dashboard that helps users explore sales performance and product-level insights efficiently.
